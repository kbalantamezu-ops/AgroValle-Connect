# Retrospective Sprint 1 — Start-Stop-Continue

## Start (Empezar a hacer)
- Realizar Daily Scrums más puntuales y con registro inmediato.
- Definir desde el inicio las ramas por historia para evitar conflictos.
- Implementar el código de los endpoints lo antes posible en el siguiente sprint.

## Stop (Dejar de hacer)
- Hacer commits directos a main sin Pull Request.
- Dejar las pruebas unitarias para el final del sprint.
- Retrasar la implementación del código frente a la documentación.

## Continue (Seguir haciendo)
- Mantener la comunicación constante del equipo.
- Usar Conventional Commits en todas las ramas.
- Verificar Checkstyle antes de cada commit.
- Mantener la documentación y el tablero Kanban actualizados.
